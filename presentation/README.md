# Presentation

20 slides (15 minutes) that follow the same order as the report
([`report/final/project_report.pdf`](../report/final/project_report.pdf)); the label at the top of each slide gives the
report section it summarises.

| Slides | Report section |
|---|---|
| 2 | §1 Business understanding: problem, research questions, success criteria |
| 3–5 | §2 Data understanding: datasets, key concepts, taxonomy, quality issues |
| 6–7 | §3 Data preprocessing: cleaning decisions, integration, leakage |
| 8–14 | §4 EDA: descriptive statistics, correlation, relationships, normality, hypothesis tests, SQ2 |
| 15–17 | §5 Feature engineering: pipeline, final feature sets, why these methods |
| 18–19 | §6 Conclusions, limitations, future modelling plan |

Every member must be able to explain any part of the code and decisions during Q&A.
