# Report

The final written report (LaTeX, written on Overleaf). Export the project from Overleaf and put the
`.tex` sources and the compiled PDF here.

Structure (follows the rubric):

1. Business understanding — context, problem statement, research questions, success criteria
2. Data understanding — sources, dimensions, variables, types, initial limitations
3. Data preprocessing — quality findings, each treatment and its rationale, merge decisions
4. Exploratory data analysis — labelled figures and tables, correlations, hypothesis tests
5. Feature engineering — final features and how they support the objectives
6. Conclusions and next steps — findings, limitations, future modelling
7. References
